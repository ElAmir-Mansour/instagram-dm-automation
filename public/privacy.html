Privacy Policy

Last Updated: May 18, 2026

This Instagram DM Automation service ("we", "us", or "our") operates as an open-source comment-to-DM automation tool. This privacy policy explains our practices regarding the collection, use, and disclosure of data.

1. Data We Collect

We receive the following data via Meta Webhooks when a user comments on an Instagram post:

  • Username — The public Instagram username of the commenter.
  • Comment text — The text content of the comment.
  • Comment ID — A unique identifier for the comment.
  • Post ID — The identifier of the post that was commented on.

2. How We Use the Data

The data is used solely to:

  • Determine if a comment matches a configured trigger keyword.
  • Send an automated Direct Message to the commenter (if a keyword matches).
  • Prevent duplicate messages by tracking recent interactions.

We do not sell, share, or transfer this data to any third parties.

3. Data Storage & Retention

Interaction logs (username, comment ID, post ID, and delivery status) are stored in a secure PostgreSQL database. These logs are used for duplicate prevention (24-hour window) and diagnostic purposes.

4. Data Deletion

Users may request deletion of their data at any time. See our Data Deletion Instructions for details.

5. Third-Party Services

This application uses:

  • Meta Graph API — To receive comment notifications and send messages. Subject to Meta's Privacy Policy.
  • Supabase — For database hosting. Subject to Supabase's Privacy Policy.
  • Vercel — For application hosting. Subject to Vercel's Privacy Policy.

6. Contact

If you have any questions about this Privacy Policy, please open an issue on our GitHub repository or contact the administrator of the Instagram account that triggered the automation.
